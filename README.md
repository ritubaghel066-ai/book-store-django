# Book Store Django

A simple and user-friendly online Book Store website developed using Django.

## Project Description

The Book Store is a web-based application that allows users to browse books, search for books, view book details, add books to a shopping cart, and place orders.

The project also includes user registration and login functionality along with an admin panel for managing books and orders.

## Features

- Home page with featured books
- Browse all available books
- Search books by title
- Filter books by category
- View detailed information about a book
- Add books to cart
- Increase and decrease book quantity
- Remove books from cart
- Checkout and place orders
- Order success page
- User registration
- User login and logout
- Admin panel for managing books and orders
- Book cover image upload
- Responsive website design
